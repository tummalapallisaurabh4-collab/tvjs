# tvjs – Beginner Setup

This repository is currently empty, so here is a simple JavaScript starter setup.

## 1) Prerequisites

- Install **Node.js 20+** (includes npm)
- Verify install:

```bash
node -v
npm -v
```

## 2) Install dependencies

```bash
npm install
```

## 3) Run the app (development)

```bash
npm run dev
```

## 4) Build and run

```bash
npm run build
npm start
```

## 5) Lint your code

```bash
npm run lint
```

## Project layout

- `src/index.js` – entry point
- `dist/` – build output

## Next steps

- Add features inside `src/`
- Add tests (for example: Vitest or Jest)
- Convert to TypeScript if you want stronger type checks
